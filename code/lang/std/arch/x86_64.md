# arch.x86_64 — x86-64 外部汇编包装器

受审查的硬件访问包装器。声明在 [x86_64.dg](x86_64.dg)，实现在本目录的 [x86_64.asm](x86_64.asm)。所有函数遵循 SysV AMD64 约定，链接名带统一 `dg_arch_` 前缀。全部声明标记 `unsafe`：被调用方可能需要特权，或其效果取决于调用方拥有的 CPU/页表状态。

## 接口

```text
pub struct CpuId { pub eax:u32, pub ebx:u32, pub ecx:u32, pub edx:u32 }

pub unsafe extern "sysv64" ("dg_arch_in8") fn in8(port:u16) u8
pub unsafe extern "sysv64" ("dg_arch_out8") fn out8(port:u16, value:u8) void
pub unsafe extern "sysv64" ("dg_arch_read_cr3") fn read_cr3() u64
pub unsafe extern "sysv64" ("dg_arch_write_cr3") fn write_cr3(value:u64) void
pub unsafe extern "sysv64" ("dg_arch_read_msr") fn read_msr(msr:u32) u64
pub unsafe extern "sysv64" ("dg_arch_write_msr") fn write_msr(msr:u32, value:u64) void
pub unsafe extern "sysv64" ("dg_arch_read_tsc") fn read_tsc() u64
pub unsafe extern "sysv64" ("dg_arch_cpuid") fn cpuid(leaf:u32, subleaf:u32, out:*CpuId) void
pub unsafe extern "sysv64" ("dg_arch_lfence") fn lfence() void
pub unsafe extern "sysv64" ("dg_arch_sfence") fn sfence() void
pub unsafe extern "sysv64" ("dg_arch_mfence") fn mfence() void
```

## 语义与契约

- `in8/out8`：u16 端口读写单个 u8。特权（CPL 0 或 IOPL 允许），仅用于特权调用环境。
- `read_cr3/write_cr3`：读写页表根。特权；调用方负责页表内容、CR3 保留位和 TLB/PGE 语义。
- `read_msr/write_msr`：读写 MSR。特权；`read_msr` 返回 64 位（EDX:EAX 合并），`write_msr` 把 `value` 拆成 EDX:EAX。调用方负责 MSR 选择与保留位。
- `read_tsc`：读时间戳计数器，返回 u64。RDTSC 本身不是序列化屏障，需要顺序语义时配合 fence。
- `cpuid(leaf, subleaf, out)`：执行 CPUID，把 eax/ebx/ecx/edx 按顺序写入 `out`（偏移 0/4/8/12）。保持 SysV 非易失寄存器，尤其 RBX（CPUID 会破坏它）。`CpuId` 只通过指针传递，不按值跨函数边界。
- `lfence/sfence/mfence`：顺序屏障薄封装。

所有特权函数不做任何状态校验：端口、MSR 编号、页表基址、保留位及 CPU 状态的合法性由调用方保证。

## 已验证

- 声明与实现均通过 ELF64 与 COFF（win64）组装。
- 宿主在用户态执行 `read_tsc`、`cpuid` 与三个 fence 的 debug/release 原生探针，核对 CpuId 布局（大小 16、字段偏移 0/4/8/12）、CPUID 厂商串、`read_tsc` 单调性，并用独立汇编探针验证 RBX 与 R12 在 CPUID 调用中保持不变。
- `in8/out8/read_cr3/write_cr3/read_msr/write_msr` 仅做编码与链接名检查，**未在宿主用户态执行**（需要 ring-0 环境，且本批不修改 P1）；其 QEMU/特权实测留待后续。

## 用法示例

```text
import arch.x86_64 as arch;
var info: arch.CpuId = arch.CpuId { eax:0, ebx:0, ecx:0, edx:0 };
unsafe {
    arch.cpuid(0, 0, &info);
    let tsc = arch.read_tsc();
}
```
