# nasm_narrow_arithmetic_function

L3：Dong自举后端。接口、运行时语义和错误状态见原任务书；本文件由用户授权 Codex 直接实现。

先验证完整描述符、自然对齐、端点、名字、整个输出及 written 与输入的别名，再验证枚举和结构。输入彼此允许重叠；失败保持所有用户字节和计数。INVALID 优先 CAPACITY，成功只写精确前缀。

每个 piece 单独生成到 1536 字节局部区。共有 12 段，总长至多 18432，求和不会回绕。符号最多 266 加冒号 LF；C44 入口最多1536；C42 出口最多192；普通内存指令每条最多128、立即数64；标签64、比较48、算术16、shift32、checked add/sub64、范围guard128、窄结果256。C36 清理最多756；零参C41调用最多298。每段代码最多组合两条128字节指令或一个独立大组件，除专门注明的常量/存槽外；均小于1536。源文件的 piece 分支是完整段表，不使用任何测试输出长度作为界。

两遍生成：第一遍完整调用实际只读依赖以验证内容和计算长度，在容量检查之前不写用户区。第二遍配置、名字和所有只读输入不变，依赖无全局可变状态且确定；相同参数、同样大小的临时区，第一次已证明成功，故第二次失败分支不可达。输入与整个输出互斥保证重放不会破坏后续输入。调用者必须保证期间没有并发修改只读输入。每段复制后才更新游标，最后才写 written。不使用巨大的最终缓冲，也不改编译器帧上限。

测试实际 Dong debug/release 编译，隔离只暂存传递依赖闭包；ELF64/COFF 均组装，原生通过显式 SysV 桥调用。独立 RIP 相对保存观察指针与宿主栈，捕获全部保持寄存器及 RAX/RDX 后恢复宿主，再断言数值；COFF 不等于 Win64 调用约定。定向测试含真实坏 Dong 语义、容量原子性和 RBX 负控，不运行 OS/VM 或全回归。

## 具体接线与分段界

生成 Pair f(lhs,rhs)：value/status。帧32，输入槽8/16，结果24/32。8/16/32位、ADD/SUB，先规范两输入，checked在64位数学结果上先D21范围判断再规范；wrapping截取低width后按signed扩展。错误为{0,1}。无论checked是否启用均验证并输出错误标签。

按 piece 索引顺序，保守长度分别为 `268,1536,256,32,32,16,256,320,192,64,384,192`，总界 3548。入口1536取依赖契约上限；多条访存按每条128累加，常量64，比较48，二元16，分支128，块标签64，shift32，guard64/128。每个子切片的预留加当前实际长度均小于1536；当前段复用单一局部区，互不累计栈数组。所有公开函数与piece均在实际debug/release编译器4096帧上限下编译通过才计交付。
