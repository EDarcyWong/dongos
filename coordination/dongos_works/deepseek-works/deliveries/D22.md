## 实现摘要

- 严格实际复用 `CR12.emit(destination=0,base,displacement,width=8,signed=false)`
  生成零扩展字节装入，再**两次** `CR16.emit(operation=2,register=0)`
  零比较。双零比较才是非零真值：byte≠0 → 第一次比较 0 → 第二次 1；
  byte=0 → 第一次 1 → 第二次 0。只调用一次会语义取反；测试以结构断言
  `src.count('unarym.emit')==2` 强制两次调用存在。
- 预检顺序：written 契约 → out 契约 → 重叠 → base 0..15 且禁止
  rsp(4)/rbp(5) → 位移 i32 范围 → 依赖返回非 OK → 组合上界（INVALID
  优先 CAPACITY）。load 段 128 字节局部、unary 段 64 字节局部，三段
  （load+unary+unary）全部组装完成后一次性发布，`*written=` 恰一次。
  任何失败完整 out/written 不变。
- `base=RAX` 合法：load 为单指令，地址在写 RAX 之前求值；探针以
  base 寄存器持有源字节地址实际执行并观察。
- 边界证明（独立 Python 模型）：load 段最大 35 字节
  （`movzx rax, byte [r15 - 2147483648]`），一段零比较恰 36 字节，
  组合上界 35+36×2=107 ≤ 256；测试断言 max_load==35、max_unary==36。
