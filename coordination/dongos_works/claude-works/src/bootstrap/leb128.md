# bootstrap.leb128：无分配 ULEB128/SLEB128 编码

```text
module bootstrap.leb128;
pub const OK:u64=0; pub const INVALID:u64=1; pub const CAPACITY:u64=2;
pub unsafe fn unsigned(value:u64, out:[]u8, written:*usize)u64
pub unsafe fn signed(value:i64, out:[]u8, written:*usize)u64
```

只编码，不解码，不生成 DWARF/ELF 节。

## 编码

- 从低位起每 7 位一组，每字节低 7 位为载荷；非末字节 bit7=1，末字节 bit7=0。
- ULEB128：输出到最高置位所在组为止；0 编码为 `00`。最长 10 字节（u64 最大值为 `FF×9 01`）。
- SLEB128：每输出一组后对剩余值做算术右移 7 位；剩余值为 0 且本组 bit6=0，或剩余值为 -1 且本组 bit6=1 时结束（继续符号扩展不改变值）。`-1`→`7F`，`64`→`C0 00`，`-65`→`BF 7F`；最长 10 字节（i64 最小值为 `80×9 7F`）。
- 两者都是最短标准形式：不存在更短的合法编码。

## 检查顺序与内存

1. `INVALID`（描述符）：`written` 非空、8 字节对齐、`[written,written+8)` 不越过地址上限；`out` 元素为 1 字节，长度乘法不会溢出，非空时指针非空且 `[ptr,ptr+len)` 不越过地址上限；空 `out` 可为 NULL。`out` 与 `written` 不得重叠。端点先确认不溢出再做重叠比较。
2. 数据：任意 u64/i64 均可编码，没有数据 INVALID。
3. `CAPACITY`：先算所需字节数 n（≤10），`out.len < n` 时返回。

非 OK 时 `out` 与 `*written` 全部不变；成功只写 `out[0..n)` 和 `*written=n`，`out` 尾部不变。循环至多 10 次，无分配、无全局可变状态、无 OS 调用。模块不导出 C 符号，测试经临时 wrapper 导出 `dong_uleb128` / `dong_sleb128`。
