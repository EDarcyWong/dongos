## 测试设计（未运行）

| 测试 | 每模式用例 | 说明 |
| --- | --- | --- |
| seeded-small-cases | 1026 | 128 个固定种子 `0xC1500..0xC157F`，每种子 3 组 0~24 个密集区间（大量同起点、端点相接、10% end=MAX、15% 起点贴近 MAX），寄存器数 1/2/3/4/5/8/16，各测精确与 +3 容量；每 16 个种子一个只读页输入；每种子再加一个变异（start>end 或 start 回退）用例，含 out 长度 0 以确认 INVALID 先于 CAPACITY。另种子 `0xC15B` 的 3000 区间（只读页，16 寄存器）及同一输入 3 寄存器 |
| equal-touching-max-empty-spill-invalid-capacity | 68 | 手算期望先断言 Python 模型：空输入（含 out 为 NULL、富余容量）、同起点、`end==start` 不释放与 `end<start` 释放、点区间、MAX 端点、选最低空闲寄存器、溢出后不驱逐/不复用槽、全部寄存器满后连续溢出；register_count 0/17/18/64/MAX；六类数据 INVALID（各含 out=0 与富余 out）；精确−1、0、+9 容量；一组只读页 |
| 原生描述符预检 | 15/每可执行文件 | result 为 NULL/未对齐/与 input 重叠/与 out 头部或尾元素重叠；out 与 input 重叠；input/out 未对齐；非空 NULL；两种长度乘法溢出；input/out/result 极端地址（均 8 对齐、无别名，只能被端点溢出拒绝）；状态 1 且 arena 逐字节不变 |

期望来自独立 Python 模型：每个寄存器保留完整占用历史，仅当其历史中所有区间 end 都小于新 start 时空闲，取最小编号。成功时另外按性质检查：溢出槽编号恰为 0..k-1 按出现顺序；分到 r 时 r 不活跃且所有更小编号寄存器都活跃；溢出时所有寄存器活跃；同寄存器区间严格不相交。C 观察器每次调用后立即检查 input 全文及前后 32 字节 guard（只读页情况检查全文）、out 前后 guard 与失败时整段不变/成功时尾部不变、Result 整体及前后 guard；Python 先检查该次 guard 再看状态与内容。debug、release 均原生执行，elf64、win64 均组装，结构布局由 C 静态断言。
