## 实现要点

先查 written、四个切片的区间与别名，再查行列、path 非空、code 长度和总长度（逐步比较，不先做溢出加法），之后才读取 code 和扫描 path/message，最后查容量并一次写出。数字从低位往回写，最多 20 位。

期望值由 Python bytes 拼接与 `str(int)` 独立计算。每次调用后 C 驱动立即检查输入全内容和前后 32 字节 guard（只读页例子放在 PAGE_READONLY 页）、out 前后 guard、written 前后 8 字节 guard；失败时整个 out 和 written 不变，成功时 out 尾部未写；Python 在读取下一条前先断言该条 guard，再比对状态、written 和完整输出。debug、release 均原生执行，elf64、win64 均组装，11 参数 SysV 调用含栈参数。
