## 实现要点

- 固定 `BASE=0x400000`、`PAGE=4096`、`TEXT_OFFSET=4096`、`LIMIT=16 MiB`。布局：`code_end = 4096 + code.len`；有数据或 BSS 时 `data_offset = align_up(code_end, 4096)`，`file_size = data_offset + data.len`，否则 `file_size = code_end`。程序头为 1 个（RX 文本段）或 2 个（再加 RW 数据段，`memsz` 含 BSS）。
- 校验顺序：written、三个描述符、written/out 与两个完整输入的别名 → code 非空且 `entry < code.len` → 各项 ≤ 16 MiB → `code_end`、`data_offset`、`file_size` ≤ 16 MiB（比较时都先减后比，不会溢出）→ 容量。所有 INVALID 都先于 CAPACITY。
- 上界证明（见说明文档）：页数 ≤ 4096 + 8193 = 12289 < `MAX_PAGES` 16384；最高地址远低于 `USER_LIMIT`；文件 ≤ `MAX_IMAGE`。
- 发布：全部失败条件检查完后，直接写最终输出（不在栈上暂存 16 MiB）：头页清零后逐字段设置，原样复制 code，填充区清零，原样复制 data，最后写 `*written`。之后不会再失败；`out` 中 `file_size` 之后的部分保持不变。
