## 实现

`emit(module_name, item_name, parameter_count, slot_count, instructions, return_slot, out, written)`，`Instruction{operation, destination, left, right, immediate}`（40 字节、8 对齐）。槽 s 在 `[rbp-8*(s+1)]`，`frame = align_up(8*slot_count,16)`，mask 0。生成顺序：CR3 符号 + `:\n` → CR11 `prologue(frame,0)` → C37（kinds 全 0、offset `8*(i+1)`）捕获参数 → 每条指令（CONST：固定 `mov rax, ` + CR4 `encode(imm,64,false)` + LF，再 CR13 存；COPY：CR12 装 rax、CR13 存；二元：CR12 装 rax/rcx、C23 `emit(op-2,rax,rcx)`、CR13 存）→ C42 `emit(8,frame,0,8*(rs+1),0)`。CR12/CR13 都是 rbp 基址、负偏移、width 64，load 为 unsigned。

预检顺序：written → 指令数组元素乘法（len ≤ MAX/40）→ 名字、指令数组（8 对齐）、out 的端点/NULL → written/out 别名 → written、out 与完整名字和完整指令数组的别名 → 名长 1..64、参数 ≤ 6、槽 1..32 且 ≥ 参数、指令 ≤ 64、return_slot < slot_count → 整串 IR（未知 operation、未用字段非零、越界、读前未初始化、返回槽未初始化）。32 个局部初始化标记，起初只有参数槽为真，本条写在本条读检查之后才置位。全部 INVALID 先于 CAPACITY。

## 与任务书的偏差（scratch 与发布方式）

任务书允许"16384 字节最终 scratch，最后一次性发布"。dongc 把单个函数的最坏栈帧限制在 4096 字节，带初始化的 `[N]u8` 约占 2N（C50 实测 N=2048 报 4592、N=3072 报 6640），未初始化数组又被检查器拒绝，所以无法用单块缓冲装下最长 6591 字节的输出。本实现用 512 字节片段缓冲分两遍：

1. IR 全部检查通过后，第 1 遍对每个片段（符号头、序言、捕获、每条指令、返回尾声，最多 68 个）真实调用组件写入片段缓冲，只累加长度，不碰 out；任何组件非 OK 返回 INVALID。
2. 总长超过 `out.len` 返回 CAPACITY，out 与 `*written` 都不变。
3. 第 2 遍重新生成同样的片段（输入只读，组件确定性），依次复制进 out，最后写 `*written`。

out 的第一个字节只在第 1 遍完整成功、容量确认之后才写，INVALID/CAPACITY 绝不留下函数头或序言；这不是"先往 out 发射再回滚"。第 2 遍与第 1 遍完全相同，不会失败。

逐项保守上界（偏移 ≤ 256，frame ≤ 256）：符号头 268；序言 35；捕获 156；CONST 57；COPY 54；二元 95；返回尾声 52；合计 ≤ 268+35+156+64×95+52 = 6591。测试里最接近最坏的输入实测 6511 字节并断言 ≤ 6591。

## 真实坏 Dong 与拒绝依据

- **SUB 左右装载互换**：6 个含 SUB 且左右不同的向量，先用正式 Dong 在 debug/release 实际生成并原生执行好侧，再编译坏体，正常编译、链接、组装、执行后按 `native rax` 拒绝。
- **提前标记 destination 已初始化**（在读检查之前置位）：3 个读未初始化槽的 IR（`ADD 3 = 3 + 0`、`COPY 1 ← 1`、`XOR 1 = 0 ^ 1`），好体返回 INVALID；坏体返回 OK，按 `status` 拒绝。只调用发射器，不执行这些非法 IR 生成的机器码。
- **容量不足时先发布函数头**（CAPACITY 前把片段 0 写进 out）：exact-1 容量下按 `guard/atomicity` 拒绝。
- **去掉名字/指令数组别名检查**（附加敏感性）：debug/release 都只让预检 15..23 失败。

坏体所有内存访问都在测试预留区域内，不靠崩溃或构建失败判定。
