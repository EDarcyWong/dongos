## 实现

`emit(functions, work, out, written)`，状态 OK/INVALID/CAPACITY/WORKSPACE = 0/1/2/3，`Function` 72 字节。顺序：`written` → 函数数 1..8（先于读取任何 Function）→ Function 数组、work、out 描述符 → written/work/out 两两不重叠且不与 Function 数组重叠 → 每个函数的嵌套描述符（名字与 IR 的端点/NULL/乘法/8 对齐/数量）及其与 written/work/out 的别名（先于读取任何名字或 IR）→ 重复 `(module,item)` 字节对（CR3 编码单射，等价于符号相等）→ 对每个函数真实调用 `f.emit(…, 空 NULL out, &局部计数)`，合法函数必须答 C48.CAPACITY，其它一律 INVALID（不复制 C48 的 IR 检查，不靠用户 out 试写）→ `work.len < B = 22 + n*(274+6591)` 返回 WORKSPACE（优先于 out 的 CAPACITY）→ 在 work 里逐函数真实生成：`bits 64\nsection .text\n` + 每个函数 `global <CR3 符号>\n` 紧跟其 C48 函数体 → 实际长度大于 `out.len` 返回 CAPACITY，否则一次性复制精确前缀并发布 `*written`。work 在完成全部 INVALID 与 WORKSPACE 检查前不写；CAPACITY 后保留生成的模块前缀；INVALID/WORKSPACE 时 work 全文不变。逐段预算证明（任意 k 剩余 ≥ 6591）与"生成阶段异常 INVALID 在当前确定性输入下不可达"的说明在 `.md` 里。无分配、无全局可变状态、无 OS 调用，不导出 C 符号。
