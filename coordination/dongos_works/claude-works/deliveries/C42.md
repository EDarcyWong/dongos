## 实现要点

- 按"C39 装载 → CR11 尾声"的顺序实际调用两个组件，没有重写任何组件。调 C39 时 frame 参数传 `extent = 8n + frame_bytes + padding`，offset 不变；调 CR11 时传原 `frame_bytes` 和 `saved_mask`。
- 本模块自己做的校验：written/out 描述符和别名；frame（0..4096，16 的倍数）；mask（只允许低 5 位）；`extent ≤ 4080`；以及**局部区窗口**——非零 offset 必须满足 `8n < offset ≤ 8n + frame_bytes`。其余（kind、未使用 offset 为 0、对齐、PAIR 两槽不同）交给 C39。所有 INVALID 都先于容量判断。
- 局部 scratch 192 字节 = C39 段 64 + CR11 段 128。实际最长输出是 56 + 66 = 122 字节（证明见说明文档）。组装完成后一次性发布。
