## 实现要点

- 描述符 INVALID：`written` 非空、8 字节对齐、端点不溢出；`out` 非空时指针非空且端点不溢出（元素 1 字节，无乘法溢出），空 `out` 可为 NULL；两者不重叠。端点检查先于重叠比较（`||` 短路），重叠计算不会回绕。
- 无数据 INVALID（任意 u64/i64 可编码）。随后先算长度（`ulen`/`slen`，≤10），`out.len<n` 返回 CAPACITY，此前不写任何字节；成功才写 `out[0..n)` 和 `*written=n`。
- SLEB128 结束条件：剩余算术右移值为 0 且本组 bit6=0，或为 -1 且 bit6=1。

Python 期望由独立的经典编码循环产生，并且用独立解码器验证：解码等于原值、仅非末字节带 bit7、长度等于闭式最短长度（无符号最小 n 使 v<2^7n；有符号最小 n 使 −2^(7n−1)≤v<2^(7n−1)）且 ≤10、去掉末组后值改变。原生输出同样经此解码/最短性检查，并与期望逐字节比较。C 观察器在每次调用后立即检查 out 前后 32 字节 guard、written 前后 8 字节 guard；失败时 out 与 written 全部不变，成功时 out 尾部不变、1≤n≤10 且 n≤cap。debug、release 均原生执行，elf64、win64 均组装。C13 仅有标量输入，无只读输入项。
