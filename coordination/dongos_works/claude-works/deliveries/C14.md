## 实现要点

1. 描述符 INVALID：`used` 非空、8 对齐；events/out 非空时非 NULL、8 对齐；`len*16` 先比较 `MAX/16` 再乘，端点 `n<=MAX-p`；out 整个声明区间、used、events 两两不重叠（events 是唯一只读输入）。
2. 数据 INVALID：遍历全部事件（含最后一个）：`value>=value_count` 或 `position==NONE`。
3. INVALID：`value_count>MAX/16`（对应元素字节溢出）。
4. CAPACITY：`out.len<value_count`。
5. 检查全部通过后才写：先把 `out[0..value_count)` 置为 `{NONE,0}`，再一遍折叠 `first=min`、`last=max`，最后写 `*used=value_count`。O(value_count+events.len)。

只给线性编号的保守包络，不做 CFG 活跃分析、phi 或跨函数寄存器分配。

期望值来自 Python 字典按 value 收集 min/max（`reference`），与 Dong 实现分开写。成功时再检查与顺序无关的性质（`envelope`）：first/last 都是该值真实出现过的位置，且包住全部位置；未出现的值是 `{NONE,0}`。C 观察器每次调用后立即检查：events 全文（只读页情形在 PAGE_READONLY/PROT_READ 页上）及前后 32 字节 guard、out 前后 64 字节 guard、used 前后 8 字节 guard；失败时整个 out 和 used 不变；成功时 out 尾部 `[value_count,no)` 不变、`used==value_count`。debug/release 都原生运行，elf64/win64 都组装，Event/Interval 布局由 C 静态断言保证。
