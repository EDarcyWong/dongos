# C27 — 64位寄存器间接调用发射

负责人：claude。状态：待领取。

module bootstrap.nasm_indirect_call。
pub unsafe fn emit(target:u64,out:[]u8,written:*usize)u64。
target仅0..15，其它INVALID；严格一行"call <target64>\n"，不是call [reg]、跳转、直接符号或ret。该组件只发射调用指令；callee地址有效性、参数/返回ABI、调用点16字节对齐和活跃caller-saved保存由上游负责，不声称完成完整函数指针lowering。
全部16目标名都做精确文本及ELF64/COFF组装；RSP/RBP只组装，不作为不受控宿主栈/地址运行。有限原生探针选rax/r10/r11等不占参数的安全寄存器，存入本探针定义且可执行的callee地址，正确保存宿主callee-saved寄存器并对齐调用点。独立callee在RAX返回参数加特定标记、在RDX返回callee入口RSP&15；观察参数、目标特有返回、入口对齐8和返回后探针栈恢复。不要要求callee保留ABI允许破坏的caller-saved寄存器；COFF能组装不等于Win64 ABI。
真实坏Dong把一个安全目标寄存器写成另一个；原生夹具须同时给两个寄存器放不同、已定义、均有效的callee地址，以错误返回标记拒绝，不得靠未知符号/非法地址/崩溃拒绝。另容量提前写原子性负控。
